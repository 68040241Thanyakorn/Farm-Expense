# Farm Expense — ระบบจัดการรายรับ–รายจ่ายฟาร์มปลา

Farm Expense เป็นเว็บแอปพลิเคชันสำหรับจัดการข้อมูลบ่อเลี้ยงปลา บันทึกรายรับและรายจ่าย ติดตามกำไร–ขาดทุน และวิเคราะห์ต้นทุนเพื่อช่วยตัดสินใจบริหารฟาร์ม โดยออกแบบให้ใช้งานผ่านเว็บเบราว์เซอร์และติดตั้งบน iPhone เป็น Progressive Web App (PWA) ได้

> **สถานะระบบปัจจุบัน:** ฟังก์ชันวิเคราะห์และตอบคำถามเกี่ยวกับฟาร์มใช้ **Rule-Based Analysis ที่พัฒนาด้วย Python** ไม่ได้เรียก OpenAI API และไม่จำเป็นต้องเติมเครดิต OpenAI ทั้งนี้ต้องใช้ `app.py` เวอร์ชันล่าสุดที่เปลี่ยน `/api/ask` ให้เรียก `farm_question_fallback()` โดยตรง

## 1. ความสามารถของระบบ

- เพิ่ม แก้ไข และแสดงรายการบ่อเลี้ยงปลา รวมถึงชนิดและจำนวนปลา
- บันทึกรายรับและรายจ่ายแยกตามบ่อและวันที่
- สรุปรายรับ รายจ่าย และกำไร–ขาดทุนตามเดือนและบ่อที่เลือก
- แสดงกราฟเปรียบเทียบและสัดส่วนค่าใช้จ่าย
- วิเคราะห์บ่อที่ทำกำไรสูง บ่อที่ขาดทุน และหมวดต้นทุนที่สูง
- ให้คำแนะนำเบื้องต้นเกี่ยวกับการควบคุมต้นทุน
- ตอบคำถามเกี่ยวกับข้อมูลฟาร์มตามเงื่อนไขที่กำหนด เช่น “บ่อไหนกำไรมากที่สุด” และ “ควรลดต้นทุนอะไร”
- ใช้งานผ่านเว็บไซต์ และเพิ่มไปยังหน้าจอโฮมของ iPhone ได้

**ข้อจำกัดของการตอบคำถาม:** ระบบเป็นการคำนวณและวิเคราะห์ตามกฎที่เขียนไว้ (Rule-Based) ไม่ใช่โมเดล Machine Learning หรือ Generative AI จึงไม่รองรับการตอบคำถามอิสระทุกประเภท

## 2. เทคโนโลยีที่ใช้

| ส่วนของระบบ | เทคโนโลยี | หน้าที่ |
|---|---|---|
| Frontend | HTML, CSS, JavaScript | สร้างหน้าเว็บ การโต้ตอบ และแสดงข้อมูล |
| Backend | Python, Flask | ประมวลผลข้อมูลและให้บริการ API |
| การวิเคราะห์ | Rule-Based Analysis | คำนวณผลประกอบการและให้คำแนะนำตามเงื่อนไข |
| การจัดเก็บข้อมูล | Browser `localStorage` (JSON) | เก็บข้อมูลบ่อปลาและธุรกรรมบนอุปกรณ์ของผู้ใช้ |
| โปรแกรมพัฒนา | Visual Studio Code | เขียน แก้ไข และทดสอบโค้ด |
| การจัดการซอร์สโค้ด | GitHub | จัดเก็บโค้ด Backend และติดตามการเปลี่ยนแปลง |
| โฮสต์ Frontend | Netlify | เผยแพร่เว็บไซต์ผ่าน HTTPS |
| โฮสต์ Backend | Render | ให้บริการ Flask API ผ่าน HTTPS |
| การติดตั้งบนมือถือ | PWA, Web App Manifest, Service Worker | เพิ่มเว็บไซต์ลงหน้าจอโฮมและช่วยจัดการไฟล์แคช |

**หมายเหตุ:** `localStorage` ไม่ใช่ฐานข้อมูลเชิงสัมพันธ์และไม่ซิงก์ข้อมูลข้ามอุปกรณ์โดยอัตโนมัติ

## 4. วิธีติดตั้งและรันบนคอมพิวเตอร์ (สำหรับพัฒนา)

### 4.1 สิ่งที่ต้องติดตั้ง

- Python
- Visual Studio Code
- ส่วนขยาย Live Server สำหรับ VS Code
- เว็บเบราว์เซอร์ เช่น Chrome

### 4.2 ติดตั้งไลบรารี Python

เปิด Terminal ในโฟลเดอร์ที่มี `app.py` และ `requirements.txt` แล้วรัน:

```powershell
py -m pip install -r requirements.txt
```

ตัวอย่าง `requirements.txt`:

```text
Flask>=3.0,<4
Flask-Cors>=4,<7
gunicorn
```

`gunicorn` ใช้สำหรับรันบนโฮสต์ Linux เช่น Render; ในเครื่อง Windows สามารถใช้ `py app.py` เพื่อทดสอบได้

### 4.3 รัน Backend แบบ Local

```powershell
py app.py
```

โดยทั่วไป Flask จะเปิดที่:

```text
http://127.0.0.1:5000
```

ถ้า JavaScript ตั้งค่าให้เรียก Backend บน Render อยู่แล้ว ไม่จำเป็นต้องเปิด Flask ในเครื่องเพื่อใช้งานเว็บไซต์ออนไลน์

### 4.4 รัน Frontend แบบ Local

1. เปิดโฟลเดอร์เว็บไซต์ใน VS Code
2. เปิด Live Server (โดยทั่วไปใช้ Port `5500`)
3. เปิดหน้าแรก `http://127.0.0.1:5500/index1.html`
4. เข้า `index8.html` เพื่อทดสอบหน้าสรุป หรือ `index9.html` เพื่อทดสอบระบบวิเคราะห์

> **ข้อควรระวัง:** `127.0.0.1` หมายถึงอุปกรณ์ที่กำลังเปิดลิงก์ จึงไม่สามารถใช้ URL ของคอมพิวเตอร์บน iPhone ได้โดยตรง ให้ใช้เว็บไซต์ HTTPS ที่เผยแพร่บน Netlify

## 5. การเชื่อมต่อ Frontend และ Backend

Backend ที่เผยแพร่สำหรับโปรเจกต์นี้:

```text
https://farm-expense-backend.onrender.com
```

ตัวอย่างการกำหนด URL ใน JavaScript ที่เรียก API:

```javascript
const API = 'https://farm-expense-backend.onrender.com';
```

ตรวจสอบ **ทุกหน้า** ที่เรียก API โดยเฉพาะ `index5.html` (คำแนะนำรายบ่อ) และ `index9.html` (วิเคราะห์และถาม–ตอบ) ไม่ให้มี URL `http://127.0.0.1:5000` ค้างอยู่ในเวอร์ชันที่ Deploy

### Backend API

| Method | Endpoint | การใช้งาน |
|---|---|---|
| POST | `/api/advice` | สร้างคำแนะนำเบื้องต้นสำหรับรายละเอียดบ่อ |
| POST | `/api/analysis` | วิเคราะห์รายรับ รายจ่าย กำไร–ขาดทุน และข้อมูลแต่ละบ่อ |
| POST | `/api/ask` | ตอบคำถามตามกฎและข้อมูลฟาร์มที่ส่งมา |

API รับข้อมูลเป็น JSON และส่งผลลัพธ์เป็น JSON การเรียก API บน Render ต้องเชื่อมต่ออินเทอร์เน็ต

### การตั้งค่า CORS

ใน `app.py` ต้องอนุญาต Origin ของเว็บไซต์ที่ใช้งานจริง ตัวอย่าง:

```python
from flask_cors import CORS

app = Flask(__name__)
CORS(app, resources={
    r"/api/*": {
        "origins": [
            "http://127.0.0.1:5500",
            "http://localhost:5500",
            "https://thriving-hamster-a3b881.netlify.app"
        ]
    }
})
```

ใช้โค้ดตั้งค่า CORS เพียงชุดเดียว และวางหลังสร้าง `app` แล้ว หากเปลี่ยนโดเมน Netlify ต้องอัปเดต Origin และ Deploy Backend ใหม่

**ความปลอดภัย:** CORS ไม่ใช่ระบบยืนยันตัวตน หากเปิด API สาธารณะควรพิจารณาเพิ่มการจำกัดคำขอและมาตรการป้องกันการใช้งานเกินความจำเป็น

## 6. ระบบวิเคราะห์แบบ Rule-Based

การวิเคราะห์ดำเนินการบน Python Backend โดยอาศัยข้อมูลที่ Frontend ส่งมา ได้แก่ บ่อที่เลือก เดือน รายรับ รายจ่าย และหมวดต้นทุน

ตัวอย่างการทำงาน:

1. รวมรายรับและรายจ่ายตามบ่อและเดือน
2. คำนวณ `กำไรสุทธิ = รายรับ - รายจ่าย`
3. เปรียบเทียบกำไรของแต่ละบ่อ
4. หาหมวดค่าใช้จ่ายที่มีมูลค่าสูงสุด
5. ตอบคำถามและให้คำแนะนำตามเงื่อนไขในโปรแกรม

ฟังก์ชันหลักที่ใช้ใน `app.py` ได้แก่ `analyze()`, `advice_for()` และ `farm_question_fallback()`

**เวอร์ชันที่ไม่ใช้ OpenAI:** เส้นทาง `/api/ask` เรียก `farm_question_fallback()` โดยตรง จึงไม่ต้องตั้งค่า `OPENAI_API_KEY` หรือ `OPENAI_MODEL` และไม่มีค่าใช้จ่ายจากการเรียก OpenAI API สำหรับฟังก์ชันนี้

## 7. การจัดเก็บข้อมูล

ข้อมูลถูกจัดเก็บเป็น JSON ภายใน `localStorage` ของเว็บเบราว์เซอร์ โดยมีคีย์หลักดังนี้:

| Storage Key | ข้อมูล |
|---|---|
| `farmExpensePonds` | รหัสบ่อ หมายเลขบ่อ ชนิดปลา จำนวนปลา |
| `farmExpenseTransactions` | รหัสรายการ รหัสบ่อ ประเภทรายรับ/รายจ่าย หมวดหมู่ จำนวนเงิน วันที่ และรายละเอียด |

**ข้อจำกัดที่ควรทราบ**

- ข้อมูลที่บันทึกบนคอมพิวเตอร์และ iPhone **ไม่ซิงก์กันอัตโนมัติ**
- การล้างข้อมูลเว็บไซต์ ลบแอป หรือเปลี่ยนเบราว์เซอร์/โดเมน อาจทำให้ไม่สามารถเข้าถึงข้อมูลเดิมได้
- ควรสำรองข้อมูลเป็นระยะ และพิจารณาเพิ่มฐานข้อมูลกลางกับระบบบัญชีผู้ใช้หากต้องการใช้งานจริงหลายอุปกรณ์
- การส่งข้อมูลไปวิเคราะห์ที่ Render ไม่ได้หมายความว่ามีการบันทึกข้อมูลเหล่านั้นลงฐานข้อมูลบน Render

## 8. เผยแพร่เว็บไซต์บน Netlify

Frontend ที่ใช้ในโปรเจกต์:

```text
https://thriving-hamster-a3b881.netlify.app
```

1. เตรียมโฟลเดอร์สำหรับ Deploy ซึ่งมี HTML, CSS, JavaScript, รูปภาพ และไฟล์ PWA ครบ
2. ให้มี `index.html` เป็นสำเนาของ `index1.html` เพื่อเปิดโดเมนหลักได้ และคง `index1.html` ไว้สำหรับ Start URL ของ PWA
3. ตรวจสอบพาธรูปภาพและไฟล์ทั้งหมดให้ถูกต้อง
4. อัปโหลดไปยังไซต์เดิมผ่าน Netlify Deploys หรือ Netlify Drop
5. เปิดลิงก์ HTTPS ทดสอบหน้าแรก รายการบ่อ สรุปผล และระบบวิเคราะห์

อย่าอัปโหลด `.env`, API Key หรือข้อมูลลับลงเว็บไซต์สาธารณะ

## 9. เผยแพร่ Flask Backend บน Render

โครงสร้างไฟล์ Backend สำหรับ Deploy:

```text
FarmExpense_Backend/
├── app.py
├── requirements.txt
└── .gitignore
```

1. อัปโหลดไฟล์ Backend ไปยัง GitHub Repository
2. สร้าง Render Web Service จาก Repository นั้น
3. เลือก Python และกำหนด Build Command:

   ```bash
   pip install -r requirements.txt
   ```

4. กำหนด Start Command:

   ```bash
   gunicorn app:app
   ```

5. Deploy และรอให้สถานะเป็น Live
6. ทดสอบ `/api/analysis` และ `/api/ask` ผ่านคำขอ POST จากหน้าเว็บไซต์

**สำหรับเวอร์ชัน Rule-Based ไม่ต้องเพิ่ม OpenAI API Key ใน Render** หากมี Environment Variable เดิมค้างอยู่และไม่ได้ใช้งานแล้ว สามารถนำออกได้หลังตรวจสอบโค้ดเวอร์ชันที่ Deploy

## 10. ติดตั้งบน iPhone เป็น PWA

1. เปิด Safari บน iPhone
2. เข้า `https://thriving-hamster-a3b881.netlify.app`
3. กดปุ่ม Share (แชร์)
4. เลือก **Add to Home Screen / เพิ่มไปยังหน้าจอโฮม**
5. ตั้งชื่อ **Farm Expense** และเลือกเปิดเป็น Web App หากมีตัวเลือก
6. กด **Add / เพิ่ม** แล้วเปิดแอปจากไอคอนบนหน้าจอโฮม

### ไฟล์ PWA ที่สำคัญ

- `manifest.webmanifest` — กำหนดชื่อ ไอคอน และ `start_url` เป็น `./index1.html`
- `pwa.js` — ลงทะเบียน Service Worker
- `service-worker.js` — แคชไฟล์สำหรับการโหลดแอป
- `icons/` — ไอคอนขนาดที่ประกาศใน Manifest

เมื่อแก้เว็บไซต์และ Deploy ใหม่ ควรเปลี่ยนชื่อเวอร์ชันแคชใน `service-worker.js` เพื่อให้ไฟล์ JavaScript/CSS ใหม่ถูกติดตั้ง การมี Service Worker ไม่ได้หมายความว่าฟังก์ชันที่เรียก Render จะทำงานแบบออฟไลน์ได้

**อย่ารีบล้าง Site Data หรือถอนการติดตั้ง PWA เพื่อแก้ปัญหาแคช** เพราะข้อมูลฟาร์มใน `localStorage` อาจสูญหาย

| AI แนะนำไม่ขึ้นใน `index5.html` | ค้นหา URL `127.0.0.1:5000` ใน JavaScript ที่หน้านี้ใช้งาน และเปลี่ยนเป็น URL Render |
| หน้า `index9.html` เชื่อม API ไม่ได้ | ตรวจสอบ Network → `/api/analysis` หรือ `/api/ask` และ Logs บน Render |
| ข้อความ CORS Error | เพิ่มโดเมน Netlify ในการตั้งค่า CORS ของ Flask แล้ว Deploy Render ใหม่ |
| HTTP 404 จากหน้า `/` ของ Backend | อาจปกติหากไม่ได้สร้าง Route `/`; ให้ทดสอบ API ที่มีจริงด้วย POST |
| หน้าบน iPhone ยังเป็นเวอร์ชันเก่า | Deploy Netlify ใหม่ ตรวจชื่อ Cache ของ Service Worker แล้วปิด/เปิดแอปอีกครั้ง |
| ข้อมูลบนมือถือไม่ตรงกับคอมพิวเตอร์ | เป็นข้อจำกัดของ `localStorage` ที่แยกตามอุปกรณ์ |
| กราฟไม่แสดง | ตรวจข้อมูลธุรกรรม เดือน และบ่อที่เลือก รวมถึง Console ในเบราว์เซอร์ |
| หน้าแรกไม่ถูกต้อง | ตรวจ `index.html` และ `manifest.webmanifest` ให้เริ่มที่ `index1.html` |

## 13. หมายเหตุสำหรับรายงานโครงงาน

- **ภาษาโปรแกรม:** Python, JavaScript, HTML และ CSS
- **Framework:** Flask
- **โปรแกรมเขียนโค้ด:** Visual Studio Code
- **ระบบวิเคราะห์:** Rule-Based Analysis (ไม่ได้ฝึกโมเดล Machine Learning)
- **ระบบจัดเก็บข้อมูล:** Browser Local Storage (ยังไม่มีฐานข้อมูลกลาง)
- **การเผยแพร่:** Netlify (Frontend) และ Render (Backend)
- **การใช้งานบนมือถือ:** Progressive Web App (PWA)

## 14. สรุป

Farm Expense เป็นเว็บแอปพลิเคชันสำหรับจัดการข้อมูลการเงินของฟาร์มปลาและให้คำแนะนำเบื้องต้นจากข้อมูลที่ผู้ใช้บันทึก โดยใช้ Python และ Flask ประมวลผลด้วย Rule-Based Analysis ร่วมกับ HTML, CSS และ JavaScript สำหรับส่วนติดต่อผู้ใช้ ระบบสามารถเปิดผ่านเว็บเบราว์เซอร์และติดตั้งเป็น PWA บน iPhone ได้ ทั้งนี้การจัดเก็บข้อมูลยังใช้ `localStorage` และยังไม่มีระบบซิงก์ข้อมูลระหว่างอุปกรณ์
